# MacroChef - Smart Recipe Nutrition and Cost Analyzer

- **Course:** WWW Development Technologies 2026 (Practical Work II)
- **Team:** NutriLab
- **Author:** Pablo Sanchez Perez

## About the project
MacroChef is a web application with a database. Users can create recipes by choosing ingredients from a catalog and writing the grams. The app calculates the total calories, macros (protein, carbs, fat), and the price per serving automatically. It also creates a clean page to print the recipe.

## Technologies
- **Backend:** PHP 8 (PDO)
- **Database:** MySQL / MariaDB (XAMPP)
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
